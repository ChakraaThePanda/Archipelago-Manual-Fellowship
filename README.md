# Archipelago-Manual-Fellowship
This AP World requires the use of the game Fellowship.

## Goal
* Complete dungeons with each heroes in the pool at the time of the latest release.
   * Your YAML options will allow you to decide which heroes you want available in the pool.
   * You will also be able to decide how many dungeons you have to complete for each hero.
   * You will also be able to decide how many locations you want each dungeons to have.
## How to play
* Complete the dungeons with the heroes you have received through Archipelago. You will start with 1 free hero.
* Once an dungeons is completed, you can send your checks for the appropriate hero.
